1. Login & Authentication

How to Log In

  1. Go to http://127.0.0.1:8000/accounts/login/
  2. Enter your email or username
  3. Enter your password (min 12 chars)
  4. Click Sign In
  5. If you have 2FA enabled, enter your 6-digit TOTP code
Default Admin: admin@ilims.lk / Test@12345678

Security Features

  • Argon2id Password hashing
  • 5 attempts Brute-force lockout (15 min)
  • 12 chars Minimum password length
  • History Last 5 passwords blocked
  • Idle Auto-logout after 30 min

4. Client Management

URL: /clients/

How to Add a Client

  1. Click + Add Client in the top right
  2. A popup modal opens (or full page if JS is off)
  3. Type the client name (e.g., "Keells Foods")
  4. Fill in contact person, email, phone
  5. Type a country name → results appear as you type
  6. Click Save Client

Features

  • ✅ SmartSelect type-ahead for Country & Region
  • ✅ Auto-generated client code (e.g., CUS-LK-WP-2026-00001)
  • ✅ Phone uniqueness validation
  • ✅ Live search filter on the list
  • ✅ Edit button (gear icon) on each row
  • ✅ Soft delete (X icon) — blocked if samples exist
5. Sample Registration & Workflow

URL: /samples/ → /samples/create/ → /samples/<id>/

Registration Steps

  1. Click + Register Sample
  2. Type or select a Client (SmartSelect)
  3. Enter Product Name (e.g., "Chicken Sausages")
  4. Select Category → Product Type auto-unlocks
  5. Choose Molecular Type: DNA Extraction / PCR-qPCR / Sequencing
  6. Select Requested Test Method (auto-filtered by molecular type)
  7. Set Priority, Storage, Due Date
  8. Click Register Sample → code auto-generated (e.g., FS-LK-WP-2026-00042)

Workflow State Machine

Sample Received → Testing in Progress → Analysis → Report Preparation → Report Ready → Report Sent
                                                       ↘ Rejected

6. DNA Extraction

URL: /dna/

  1. Click + Log Extraction
  2. Select the Sample (SmartSelect)
  3. Choose Extraction Method (Spin Column, Magnetic Bead, etc.)
  4. Set Date, Kit Name, Operator
  5. Optional: Concentration, A260/280, A260/230, Volume
  6. Click Save → auto-advances sample to "Testing"
7. Molecular Tests (PCR / qPCR / Sequencing)

URL: /tests/

  1. Click + Register Test
  2. Select Sample and Test Type
  3. Choose Primary Target from microorganism catalog
  4. Fill in Run Date, Instrument, Operator
  5. Add Result Lines: organism + detection + Ct value
  6. Click Save → auto-creates a QC record for review

9. QC Queue & Four-Eyes Approval

URL: /qc/

Four-Eyes Rule: The technician who ran the test CANNOT approve their own QC record. A different QC officer must review it.
  1. Go to /qc/ — see all pending reviews
  2. Click Review on a pending item
  3. See the full test context: sample, operator, result lines, Ct values
  4. Choose Decision: Approved / Rejected / Rework
  5. Choose Safety Classification: Safe / Unsafe / Needs Review
  6. Add Notes (required for Rejected/Rework)
  7. Click Save Review → sample auto-advances to next state
10. Reports & PDF Generation

11. Reminders & Notifications

Reminders (/reminders/)

  • Auto-created by cron every 15 minutes
  • Types: Due Soon, Due Today, Overdue, QC Pending
  • Actions: Done, Snooze 1d/3d, Open, Reassign
  • Tabs: Today | Upcoming | Overdue | Priority | Done

Notifications (/notifications/)

  • Topbar bell polls every 45 seconds
  • Created by state changes, QC decisions, reminders
  • Mark individual or all as read
  • JS-off fallback: full notification page
12. Cryptographic Audit Trail

URL: /audit/

  • Every CREATE, UPDATE, APPROVE, STATUS_CHANGE, EXPORT is logged
  • Each record has a SHA-256 hash chained to the previous record
  • Click Inspect to see full diff and hash chain
  • Click Verify Hash Chain to prove no tampering
  • Click Export CSV to download the full audit log
